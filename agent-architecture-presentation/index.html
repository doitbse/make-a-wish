Make-a-Wish Agent: Architecture Walkthrough Press 'S' to Toggle

Architecture Pitch for Manager, VP, and Director:

  • Left to Right Flow:
    1. Zone 1 (Ingestion): User taps the floating widget in any web app. It captures high-res screenshot annotations and automatically extracts the user's Google Cloud IAP email without forms.
    2. Zone 2 (AI & Orchestration): Cloud Run orchestrator invokes Gemini 3.8 Flash using the Google ADK. System instructions are pre-cached for 30 minutes, cutting latency to sub-second.
    3. Zone 2 (Semantic Vector Search): Agent checks Cloud Firestore using findNearest(COSINE):
      • Branch A (Duplicate >80%): Calls upvote_feature_request(). Upvotes the existing feature on the /vote board and adds an audit comment. Zero duplicate PR spam.
      • Branch B (Unique): Advances to autonomous coding.
    4. Zone 3 (Sandboxed Execution): Spawns an ephemeral git worktree in /tmp. Uses surgical tools (search_code, replace_in_file) and executes npm run build && npm test before committing.
    5. Zone 4 (Delivery & Self-Healing Loop): Pushes branch and opens GitHub PR with auto-generated PRD spec. If reviewers comment on the PR, the Review Resolver agent listens via webhook, applies fixes, pushes new commits, and auto-resolves review threads via GraphQL.
  • Executive Bottom Line: Total end-to-end turnaround is under 45 seconds, 100% sandboxed inside DoiT's GCP perimeter, and human engineers retain final merge approval.
